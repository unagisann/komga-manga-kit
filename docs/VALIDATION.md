# 基盤の検証記録

- Python 3.13環境で依存関係を隔離インストール。
- `python -m unittest discover -s tests -v`: 37件成功。
- 設定のパス解決、未知の設定・危険な階層・不正なテンプレートの拒否。
- 全角/半角カナ、五十音、整数巻・小数巻の扱い。
- ComicInfo.xmlとseries.jsonの優先順位、壊れた書庫、XMLエンティティの拒否。
- 整理先の衝突、既存ファイル、シンボリックリンクの扱い。
- スキャン・整理プレビュー前後のサンプルファイルのハッシュ一致。
- Komgaの代表的な模擬応答、認証ヘッダー、サブパス、タイムアウト、リダイレクトの扱い。
- サーバー初期化の分離、機能の追加、キーの非表示、任意のBasic認証。
- 8作品・22冊のサンプルCBZを生成し、CLIでデモ無効のスキャン・整理計画を実行。
- JavaScriptの構文確認。
- Docker Composeの設定検証、イメージビルド、非root・読み取り専用コンテナでの起動。
- ホストとコンテナで6画面、ヘルスチェック、静的アセット、蔵書APIのHTTP応答。
- Chromiumで6画面を1440px/390px幅で確認。ページ全体の横はみ出しなし。
- ブラウザでテーマ切り替え、整理プリセットの反映、不正な階層のエラー、Komga未設定時の表示を確認。
- 画面の実行時JavaScript例外なし。入力エラーの400、接続未設定の502は想定どおり。
- 秘密設定、サンプル書庫、仮想環境、実行データのGit除外を確認。

ローカル画面の記録は `var/preview-desktop.png` と `var/preview-mobile.png` に保存。
検証用サーバーとコンテナは確認後に停止。既存の運用環境は使用していない。
