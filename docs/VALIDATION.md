### Komga 1.29.0の実機確認

Raspberry Piの既存運用と分けた専用コンテナで、架空書庫だけを使用した。
公開先はループバックの別ポート、設定・書庫・DB・認証情報はGit対象外の `var/` へ分離。
既存運用のDB・蔵書・ユーザー・読書情報は使用していない。

| 検証 | 結果 |
| --- | --- |
| 接続、架空8作品22冊の読み取り・作品パス照合 | 成功 |
| 名前変更と完結フォルダへの作品単位の移動 | 成功 |
| 2ユーザーの未読・途中・読了、読書日時の引き継ぎ | 成功 |
| 移動後に進んだ最新ページを復元後も保持 | 成功 |
| ロックした作品の並び順、series.json、ローカル編集の引き継ぎ | 成功 |
| 移動先を削除した後のバックアップ復元と全ファイルSHA-256一致 | 成功 |
| 書籍/作品ID、既読レコードの作成日時の維持 | 維持されない。新しいレコードへ変わる |

`tests/komga_integration.py` の明示的な実機テスト1件が成功。

ハッシュ計算完了・自動スキャン/変換無効・ゴミ箱自動削除無効・同じ内容の重複なしを条件とする。
