# 既存Toolsの機能を揃える

2026-10-18の方針: 既存Toolsの機能を先に揃え、その後で必要・不要、画面配置、操作感を整理する。
実際の既存画面・ルート・処理を比較対象にして、公開版へ独立して実装する。
運用コード・秘密情報・状態・蔵書・Git履歴は取り込まない。
漫画のダウンロード・取得候補検索・ダウンローダー連携は引き続き対象外。

今回の変更は未リリース。[操作・設定ガイド](TOOLS.md) と [検証記録](VALIDATION.md) を参照。

| 機能 | 今回追加した内容 | 確認範囲・残る差 |
| --- | --- | --- |
| ノーマライズ | 差分、名前・配置、CBZ化、ページ順、確認、実行、復元 | Komga 1.29.1で移動→同じパスで再生成。2ユーザーの既読・読了日・中断からの復元を確認 |
| 取り込み後処理 | スキャン・解析待ち→書誌・読み・著者→タグ、任意の反映、ステップ別の記録・再開 | 自動反映は別途有効化。中断したKomga反映は履歴から確認・復元してから再開 |
| 書誌対応付け | 楽天Books・Kobo・MangaUpdates、個別修正・解除、未登録分／全作品の対応付け構築 | 楽天は公式仕様・模擬応答。MangaUpdatesは公開APIへ架空語で接続確認。実作品の照合は未検証 |
| 新刊 | 紙・電子、最新巻・予約、分冊等の除外、日付精度、差分／未登録／強制更新、任意の通知 | 取得元・版・著者が曖昧なら確認用に残す。Webhookは模擬応答で検証 |
| ポータル | 最近追加した最新巻、完結抽選・選び直し、作品・巻の詳細、今期アニメ、所持作品の新刊、今日のおすすめ、Komgaリンク | Komga未接続では登録日時の代わりに明示更新で初めて確認した日時を使う。作品詳細は専用ページ |
| 蔵書検索 | 既存Toolsのライブラリ探索と同じ画面。読者層・状態・年代のチップ（全体の件数つき）、検索語、作者（複数作品）・出版社（上位24社）、名前／評価／新しい／古い／巻数／ランダム順、60件ずつ追加表示 | 年代は連載開始年から求め、電子版発売年とは分離。未取得の書誌は手動設定も可能。Komga未接続では「読む」を出さない |
| 発見 | 既存Toolsと同じ表紙中心の画面。日替わり5作品（蔵書3・未所持2）、テーマ別・最近完結の特集切り替え、所持・作品名・著者での絞り込み、Komga・紹介記事・作品情報へのリンク、所持判定の修正、記事と蔵書の明示更新 | ぶくまるの公開RSSで10記事106作品（テーマ71・完結35）を解析確認。旧キャッシュは表示可能で、特集情報は更新後に反映。楽天Kobo・マンバ・ナタリーの既存URLも維持 |
| 今期アニメ | 当季＋前季からの継続、漫画原作・漫画版、所持照合・手動修正・更新 | AniList仕様と模擬応答。漫画版を持つ小説原作を一律に除外しない |
| ランキング | 次にくるマンガ大賞の年・部門、全年更新、所持照合・修正 | 公開2025年ページを解析確認。未公開の年は前回結果を保持 |
| スマート本棚 | アニメ・受賞・新刊のCollection、完結抽選Read List、差分確認・同期・復元 | 隔離Komgaで確認。作成したIDだけを更新し、個人の同名本棚は引き継がない |
| 完結移動 | 候補・差分・移動・履歴・復元、Komgaタグ／連載状態の反映画面 | 移動と完結情報の反映は段階ごとに確認。無確認の一括連鎖にはしていない |
| 表紙・ページ修正 | サムネイル、表紙変更、並べ替え、不要ページの削除、保留・確認済み、復元・ゴミ箱・完全削除 | Komga連携中はページ数を保つ表紙・順序変更まで。ページ数が変わる削除の既読位置移行は未対応 |
| AI補助 | 読み・導入のあらすじ・読者層、モデル選択、根拠、任意のGemini検索、確認・編集・保存・復元、既存あらすじの点検 | Chat Completions互換／Geminiを模擬応答で検証。実モデルへの接続・課金を伴う生成は未実施 |
| 読書状況 | アカウント別、読了・途中・60日以上の中断、巻の進捗・しおり画像 | 2ユーザー本人のAPIキーで実機確認。Komga DBを直接開かない |
| 設定 | 接続・情報源・AI・モデル・読書アカウントの保存、認証情報の専用ファイル登録、接続確認 | 環境変数が優先。認証情報は画面・状態DB・ジョブへ返さない |
| 自動更新 | 有効・無効、時刻・ステップ、今すぐ実行、ログ・再開、ノーマライズ後の処理 | アプリ内で日本時間の日次実行。ホストの既存タイマーは操作しない |
| PWA | インストール用manifest、Service Worker、オフライン案内 | 蔵書・進捗・API応答はオフライン保存しない。実端末のインストール試験は未実施 |
| Windowsの1冊変換 | `convert-one`、計画・確認、有効化、元ファイルを保持したCBZ生成 | POSIXで処理経路を検証。Windows実機とWindows上のlibarchiveは未検証 |

機能を削る判断とレイアウトの仕上げは次の段階。
上記の残る差・未検証範囲を、画面が存在することと混同しない。
