楽天Booksの書誌検索

{{ '架空データでお試し' if settings.demo else '設定済み' if catalog.configured else '未設定' }}

自動補完で作品をまとめて選び、読み・著者・出版社などの不足項目を補えます。取得した内容を確認して保存します。

config.yaml の rakuten.enabled: true と、環境変数 {{ settings.rakuten.application_id_env }}・{{ settings.rakuten.access_key_env }} を設定します。楽天に登録したオリジンを送る場合は rakuten.origin を指定してください。変更後は再起動します。

自動補完の候補取得や個別検索を始めたときだけ通信します。デモ中は認証設定にかかわらず架空の書誌データを使用します。

AniListのタグ・ジャンル補完

{{ '架空データでお試し' if settings.demo else '有効' if catalogs.anilist.configured else '無効（既定）' }}

作品名で漫画を探し、ジャンルとタグを確認して保存できます。楽天Booksの対応付けと一緒に保持します。同梱の対訳表で日本語にし、成人向け・関連度の低いタグやネタバレ指定のタグは除外します。

config.yaml の anilist.enabled: true を設定し、再起動してください。APIキーは不要です。自動補完の候補取得や個別検索を始めたときだけ作品名をAniListへ送信します。デモは架空データを使います。

      Webのノーマライズ実行

      {{ '有効' if settings.web_execution_enabled and not settings.demo else '無効（プレビュー専用）' }}

      設定ファイルで以下を指定し、再起動すると、変更内容の確認後にCBZ化・ページ順・名前と配置の整理を実行できます。元書庫は実行データへバックアップします。

      execution:
  enabled: true
  web_enabled: true

      ローカル以外から実行する場合は MANGA_KIT_ADMIN_TOKEN による管理者認証が必要です。Komga 1.29.1では、移動後に同じパスでCBZを再生成し、書籍ID・既読位置・読了日を照合します。ページ数が変わる削除は対象外です。

      CLIの整理実行

      {{ '有効' if settings.execution_enabled else '無効（既定）' }}

      移動・CBZ生成・バックアップ・復元と、Komgaへの作品情報の反映・復元は、設定で execution.enabled: true にしたCLIから利用できます。Webからのノーマライズ・Komga反映は、以下の追加設定で有効にできます。手順とKomga連携の条件はREADMEの整理実行ガイドを参照してください。

      設定ファイルの例

      config.yaml
      app:
  name: {{ settings.name }}
  demo: false
library:
  root: /path/to/your/manga
layout:
  status_folders:
    ongoing: {{ settings.layout.ongoing_folder }}
    completed: {{ settings.layout.completed_folder }}
    unknown: {{ settings.layout.unknown_folder }}
  series: "[{author}] {title}"
  completed: "{status}/{kana_row}/{series}"
komga:
  base_url: http://localhost:25600
  api_key_env: KOMGA_API_KEY

      APIキーは設定ファイルに含めず、環境変数から読み取ります。詳細はプロジェクトのREADMEを参照してください。
